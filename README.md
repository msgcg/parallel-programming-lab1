# Лабораторная работа №1: Программирование сетевых приложений с помощью интерфейса сокетов

**Дисциплина**: Параллельное программирование (Распределенное программирование)  
**Авторы**: Эрденко М. Д., Разгуляев Е. О. (группа ПО-32б, ЮЗГУ)  
**Преподаватель**: Ефремова И. Н.

## Описание
Реализация клиент-серверного взаимодействия на языке Java с использованием датаграммных сокетов (`DatagramSocket`, `DatagramPacket`) по протоколу UDP.

## Состав репозитория
- `UDPServer.java` — серверная часть, прослушивающая UDP-порт 1501, принимающая датаграммы от клиентов и отправляющая ответы.
- `UDPClient.java` — клиентская часть, отправляющая запросы на сервер и принимающая ответные пакеты.
- `run_test.py` — скрипт автоматизированного тестирования сетевого взаимодействия.

## Запуск
```bash
# Компиляция
javac UDPServer.java UDPClient.java

# Запуск сервера
java UDPServer

# Запуск клиента (в отдельном терминале)
java UDPClient
```
