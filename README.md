## Описание работы
Реализация клиент-серверного взаимодействия на языке Java с использованием датаграммных сокетов (`DatagramSocket`, `DatagramPacket`) по протоколу UDP с **многопоточной архитектурой обслуживания нескольких клиентов одновременно**.

### Особенности реализации
1. **Пул рабочих потоков (`ExecutorService`)**: сервер принимает входящие датаграммы без блокировки основного потока приема и передает задачи на обработку в пул потоков (размер пула: 8).
2. **Учет сессий клиентов (`ClientSession`)**: сервер отслеживает уникальные подключения по `SocketAddress`, сохраняя статистику запросов и время активности в потокобезопасной коллекции `ConcurrentHashMap`.
3. **Параллельное обслуживание**: множество клиентов могут отправлять датаграммы одновременно, не ожидая завершения запросов других пользователей.
4. **Консоль администратора**: сервер поддерживает неблокирующее интерактивное управление через консоль (`list` — список активных клиентов, `stats` — статистика обработанных пакетов, `stop` — корректная остановка).
5. **Поддержка команд клиентами**: `PING`, `TIME`, `WHOAMI`, `STATS`, `CALC <выражение>`, `REVERSE <строка>`, `BYE` (отключение отдельного клиента без остановки всего сервера).

## Состав файлов
- `UDPServer.java` — многопоточный UDP-сервер (пул потоков, учет сессий, обработка команд).
- `UDPClient.java` — интерактивный UDP-клиент.
- `MultiClientTest.java` — автоматизированный Java-тест одновременного обращения нескольких клиентов.
- `run_test.py` — кросс-платформенный скрипт тестирования многоклиентского сервера на Python.
- `.vscode/` — конфигурационные файлы для разработки и запуска в Visual Studio Code (`tasks.json`, `launch.json`, `settings.json`).

## Сборка и запуск

### 1. Компиляция
```bash
javac UDPServer.java UDPClient.java MultiClientTest.java
```

### 2. Запуск сервера
```bash
java UDPServer
```

### 3. Запуск интерактивного клиента
В отдельном терминале:
```bash
java UDPClient
```

### 4. Запуск многопоточного стресс-теста нескольких клиентов
```bash
java MultiClientTest
# или через Python:
python run_test.py
```
